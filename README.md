# 瞬間英作文 Trainer v0.4

日本語を見て英語を発話・入力し、自己評価で復習するiPhone Safari向けWebアプリ。

公開URL: https://kazuya516.github.io/instant-english-trainer/

## 使い方

1. 「問題集・記録」でGoogleスプレッドシートから書き出したUTF-8 CSVを取り込む。
2. 学習ホームで5・10・15問を選んで開始する。
3. 英語で答え、模範解答を確認して「言えない／迷った／即答できた」を押す。
4. 苦手だけ練習する場合は「苦手集中復習」。改善すると苦手リストから卒業する。

CSV必須列は「日本語」と「自然な英語」（「英語」「英文」「English」「en」も可）。任意列は「ID」「場面」。引用符で囲んだカンマ・改行・引用符とBOMに対応。重複IDはエラー。日本語または英語が空の行は除外して件数を表示する。

取り込みは問題集の置換。同じID・日本語・英語の履歴のみ維持する。安定したIDを推奨。CSVは端末内で処理し、Googleスプレッドシートの公開設定は不要。

## 復習の仕様

- 通常学習: 予定日を迎えた苦手 → 他の復習 → 未学習。未来の問題は出題しない。
- 言えない: 同セッションで**別の3問を挟んで**再出題し、長期予定は翌日へ。再失敗も同じ処理。
- 迷った: 同セッション再出題なし、翌日へ。苦手フラグを解除。
- 即答: 連続成功に応じて2、4、8、16、30日後（以降30日）。苦手フラグを解除。
- 言えない／迷ったで連続成功をリセット。
- 苦手モード: 予定日に関係なく苦手のみ出題し、通常学習と履歴を共有。
- 5・10・15問は**回答回数**。再挑戦も含む。上限で終了し、残った再挑戦は翌日または苦手モードへ。
- 間に挟む問題が足りないとき、未来の問題や即時反復で穴埋めせずに終了する。
- 日付は利用端末の現地日付。時刻ではなく日付単位で予定を比較する。
- 途中終了・再読込でも回答済み履歴は残る。セッションの未回答部分は再開せず、新しいセッションを開始する。

## データ・音声

記録は`localStorage`の`iet-v3`に端末ごとに保存。クラウド同期なし。旧版の`iet-cards`は可能な場合引き継ぎ、旧履歴は初期化。旧キーは削除しない。JSONバックアップ・復元を用意。復元は検証に成功し、利用者が確認してから置換する。

iPhoneは英語キーボードの音声入力が基本。Web Speech Recognitionは任意の試験機能で、ブラウザ提供元が音声を処理する場合がある。認識失敗・非対応時はキーボードを案内する。

読み上げはWeb Speech Synthesis。任意のサイレント対策は、対応ブラウザで読み上げの間だけ`navigator.audioSession.type = 'playback'`を試し、終了・停止・非表示時に`auto`へ戻す。標準設定はオフ。iOS・音声ごとの制約があり、サイレント中の動作は保証しない。無音ファイルによる回避・外部TTSへの例文送信・APIキーは使用しない。

参考: WebKit https://bugs.webkit.org/show_bug.cgi?id=237322 と https://github.com/w3c/audio-session/issues/46 。読み上げ用設定とマイク利用の競合を避けるため、認識前に音声セッションを戻す。

## 開発・更新

依存パッケージ・ビルド不要。Node.js 24で:

```sh
npm run check
npm test
```

ファイル構成:

- `index.html`: 画面・アクセシビリティ
- `styles.css`: iPhone幅を考慮したUI
- `app.js`: UI・保存・音声・インポート
- `core.js`: 日付・復習・CSV・バックアップ検証
- `demo.js`: 施術・スポーツ・日常のサンプル20問
- `tests/core.test.mjs`: 復習間隔・短期再出題・CSV・バックアップの回帰テスト
- `.github/workflows/test.yml`: mainとPRで検証

GitHub Pagesは現在のmain / root配信を継続する。ルートのHTML・CSS・JSとアイコンを配信し、パスはすべて相対指定。Service Workerは使わない。リリース時はJS/CSSとモジュール依存先のバージョンクエリも更新し、キャッシュ混在を避ける。

### Workへの次回の依頼

「instant-english-trainerに○○を追加して」でよい。AGENTS.mdに作業手順と要件を記録済み。毎回最新のmainを取得し、実装・検証・コミット・公開確認まで行う。

### 公開手順と権限

1. 最新mainを取得し、差分と公開設定を確認する。
2. 変更前コミットをバックアップブランチまたはタグに保存する。
3. 修正し、上記チェックとブラウザの学習フローを確認する。
4. GitHub連携が書き込めるならAPIまたはGitでコミットする。403 `Resource not accessible by integration`は、リポジトリの所有者権限表示だけでは解決しない連携アプリの権限問題。
5. 連携が書けない場合、利用者が許可したGitHub Webのログイン済みセッションで編集・複数ファイルアップロードを使う。本人認証が必要なら、安全な認証フローを使い、秘密情報をチャットやソースへ書かない。
6. mainへ反映後、GitHub Pagesのデプロイ完了と公開URLでバージョン・主要操作を確認する。未確認の公開を完了扱いにしない。
7. 元に戻す場合は公開コミットをrevertする。履歴のforce pushはしない。

GitHub連携権限が改善されるまでは、Webログインが切れたときに本人の認証が必要。完全無人の更新を保証するものではない。

## v0.4 — 表示言語と録音・聞き比べ（2026-10-28）

- 画面上部で日本語／Englishを選択。ボタン・説明・進捗・結果・確認ダイアログを切り替える。言語選択は`iet-ui-language`に保存。
- 問題文・模範解答・入力中の回答・CSVの場面は教材として保持し、UI切り替えで変更しない。学習済み履歴スキーマはv0.3と同じで、既存履歴を維持。
- 問題を見た直後は「初回を録音」、模範解答を表示した後は「練習後を録音」。2つの録音を区別して、単独再生・お手本→録音の順次再生・個別ダウンロードができる。
- 自己評価は、答えを見る前の回答を基準にする。録音や再生は任意で、既存のテキスト学習・復習日程を変えない。
- 録音はMediaRecorder/getUserMediaで端末内に保持。API・ネットワーク送信なし。最大60秒で自動停止。対応形式を機能検出する。
- 録音は現在のセッション中の一時データ。セッション終了・ページ再読込で消去。前の問題の録音は画面から戻せないため、必要な音声は次の問題に進む前にダウンロードする。JSONバックアップには音声を入れない。
- 許可待ち・録音・停止処理中は回答操作をロック。画面非表示・問題移動・終了・データ画面への移動で録音を中断し、マイクを解放。遅れて許可されたマイクも解放する。
- Safariでお手本後の録音自動再生が制限された場合、個別の再生ボタンを案内。
- `i18n.js`はUI辞書とUI更新、`recording.js`は録音の状態管理と操作を担当。録音状態はテストで検証可能なLocalRecorderとして分離。
- 自動テスト計22件：既存の復習・CSVに加え、二種類の録音、取り直し、権限拒否、許可待ち中断、録音中断、60秒制限、停止イベント未着の復旧、翻訳を検証。
- クラウドブラウザで日英切り替え、入力と問題文の維持、英語UIでの再出題・結果表示を確認。iPhone実機での収音品質・音量・サイレント設定・連続再生は別途確認が必要。
